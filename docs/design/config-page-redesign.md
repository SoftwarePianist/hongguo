# 晴空白 · Clear Daylight

> 红果模块配置页视觉重构设计哲学

## 哲学宣言

**空间即奢华。** 页面不堆砌元素，而以留白组织视线。暖白纸面托起纯白卡片，信息如同悬浮在晨光中的器物——彼此之间永远隔着恰好的呼吸距离。每一处间距都来自同一把 4dp 的尺子，每一次对齐都经过反复推敲。最终的页面必须看起来像由领域顶尖工匠耗费无数小时打磨而成：没有一个像素是随意的。

**色彩即情绪。** 抛弃灰暗与沉闷。底色是清晨的暖白（`#FAF9F8`），卡片是纯净的白，唯一的色彩主权属于品牌红橙——它以一道克制的渐变（`#FF5A3C → #FF8A5C`）出现在全页唯一的主动作按钮上，如同素白画布上的一笔朱砂。其余一切色彩退居二线：文字是温润的深褐黑，次级信息是雅致的石灰暖灰。色彩的稀缺性本身就是高级感。

**层次即秩序。** 信息分三层：纸面（背景）、器物（卡片）、铭文（内容）。卡片不以沉重阴影标榜存在，而以一根发丝般的描边（hairline）轻轻勾勒边界——这是现代界面最内敛的自信。卡片之内，标题、说明、内容区依 16sp / 12sp / 13sp 的字级阶梯排布，分割线仅出现于需要喘息的列表之间。层级靠空间与字重表达，而非色块的堆叠。

**圆角即性格。** 全页只有四个圆角值：20dp（卡片）、14dp（控件）、12dp（内嵌信息块）、全圆（胶囊）。这套圆角家族如同一套字重系统，贯穿每一个组件，绝无例外。统一不是单调，而是深思熟虑后的纪律。

**动效即质感。** 页面入场时，内容以 240ms 的轻微上浮淡入依次呈现，如帷幕徐启；按钮按下时，ripple 涟漪自触点晕开，主按钮伴随明度的细微下沉。所有动画短促、克制、服务于反馈——绝不为炫技而存在。质感的本质，是对细节的偏执。

**光影即工艺。** 全页只允许一处"光"：主按钮的渐变。它是页面的视觉锚点，也是品牌温度的唯一出口。其余表面保持哑光的平静。这种近乎苛刻的节制，正是大师级执行力的体现——知道何时不做什么，比知道做什么更难。

## 色彩规范

| 角色 | 浅色 | 深色 |
|---|---|---|
| 页面底色 app_bg | `#FAF9F8` 暖白 | `#141210` 暖墨 |
| 卡片 surface | `#FFFFFF` | `#1E1B18` |
| 内嵌块 surface_muted | `#F5F3F1` | `#26221F` |
| 主文字 text_primary | `#1C1917` | `#F5F3F0` |
| 次文字 text_secondary | `#8A837C` | `#A89E94` |
| 品牌主色 accent | `#FF5A3C` | `#FF7A5C` |
| 渐变尾色 accent_end | `#FF8A5C` | `#FF9A7A` |
| 描边 border | 8% 黑 | 10% 白 |

## 字级与间距

- 字级阶梯：28sp（页题）/ 16sp（卡题）/ 14sp（控件）/ 13sp（正文）/ 12sp（说明）
- 间距网格：4 / 8 / 12 / 14 / 16 / 20 / 24 / 32 dp，全部取自 4dp 基线
- 大屏（sw≥600dp）页面左右边距 20dp → 48dp，内容保持居中呼吸
